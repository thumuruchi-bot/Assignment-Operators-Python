# Assignment Operators (Python)

## Description
A simple Python program demonstrating assignment operators.

## Features
- Assignment (=)
- Add and Assign (+=)
- Subtract and Assign (-=)
- Multiply and Assign (*=)
- Divide and Assign (/=)

## Technology Used
- Python

## Output

After -= : 10
After *= : 20
